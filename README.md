# makayladecoded.com

Personal blog and portfolio site for Makayla Ferrell.

**Live site:** [makayladecoded.com](https://makayladecoded.com)

## Tech Stack

- [Astro 5](https://astro.build)
- [Tailwind CSS v4](https://tailwindcss.com)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
